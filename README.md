# airbyte-social-connectors (reference copy)

Unmodified copy of five connectors from [airbytehq/airbyte](https://github.com/airbytehq/airbyte),
taken at commit `7b5248b31c2a56ea37da3b96b78b7ab8fdde0329` (2026-09-25), for local code search:

- source-facebook-marketing
- source-facebook-pages
- source-instagram
- source-linkedin-ads
- source-linkedin-pages

Plus their docs in `docs/integrations/sources/`.

`searchable/` holds verbatim copies of the YAML manifests, JSON schemas and docs as
Python string modules, because the code-search corpus only indexes code files.
They are generated by `tools/make_searchable.py`; the originals are unchanged.
